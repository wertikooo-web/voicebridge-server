## Что это за проект

VoiceBridge — голосовое устройство для мгновенной связи пожилых родителей с детьми.
Без звонков. Без экранов. Нажал — говоришь. Второй слышит.

Lunara — AI-компаньон поверх того же железа (Горизонт 2).
Двойное касание → STT → LLM → TTS. Активируется когда рядом нет живого человека.

---

## Стек. Не меняй без явной команды

| Слой | Решение | Причина |
|---|---|---|
| Железо | ESP32-S3 | WebSocket, I2S, достаточно RAM |
| Микрофон | INMP441 | I2S, хорошее SNR |
| Усилитель | MAX98357A | I2S, без внешнего питания |
| Протокол аудио | PCM 16kHz 16-bit Mono | Минимальная задержка |
| Транспорт | WebSocket | Двусторонний стриминг |
| Сервер | Node.js relay | Без сохранения аудио, stateless |
| TTS (русский) | Yandex SpeechKit | Jane / Omazh голоса, SSML — решено |
| TTS (румынский) | ❓ Открытый вопрос | Кандидат: Cartesia |
| TTS (английский) | ❓ Открытый вопрос | Кандидат: Cartesia |
| AEC (эхоподавление) | Server-side (MVP) | ESP32-ADF — Горизонт 2 |

**Целевая задержка:** < 1 секунды end-to-end.

## Архитектура (текущая)

```
Телефон (приложение)
    ↓↑ WebSocket (full-duplex)
Node.js Relay Server
    ↓↑ WebSocket (full-duplex)
ESP32-S3 устройство
    → INMP441 (вход) / MAX98357A (выход)
    → RGB LED (статус)
```

**Световые сигналы:**
- 🔵 Синий = ожидание
- 🩵 Бирюзовый = активная связь (Live Line открыт)
- 🔴 Красный = оффлайн
- 🟣 Фиолетовый = Lunara AI активна

## MVP фичи (только это сейчас)

1. **Live Line** — зелёная кнопка в приложении открывает full-duplex голосовой канал.
   Оба конца говорят и слышат одновременно, как по телефону. Таймер сессии настраивается (по умолчанию 3 минуты). Push-to-talk НЕ используется — режим рации отклонён как неудобный для пожилых.
2. **Wants to talk** — короткое касание кнопки на устройстве = сигнал "позвони мне" в приложение
3. **Help request** — долгое нажатие = экстренный сигнал семье

Всё остальное — Горизонт 2. Не предлагай и не реализуй без явной команды.

## Live Line — техническое описание (MVP)

**Что это:** full-duplex WebSocket аудиоканал между приложением и ESP32.

**Как работает:**
1. Пользователь нажимает зелёную кнопку в приложении
2. Приложение отправляет сигнал `live_line_start` на Node.js relay
3. Relay открывает двусторонний канал к ESP32
4. Оба конца одновременно стримят PCM 16kHz 16-bit Mono
5. Таймер на сервере закрывает канал по истечении времени (или по кнопке)
6. ESP32 светится бирюзовым пока канал открыт

**Эхоподавление (AEC) — MVP решение:**
- AEC реализуется на сервере (Node.js), не на ESP32
- Причина: быстрее запустить, достаточно для первых тестов
- Горизонт 2: перенести AEC на ESP32 через ESP-ADF для снижения задержки

**Что НЕЛЬЗЯ:**
- ❌ Реализовывать push-to-talk вместо full-duplex
- ❌ Сохранять аудио сессий на сервере
- ❌ Открывать канал без явного действия пользователя

## Принятые решения (лог)

| Дата | Решение | Причина |
|---|---|---|
| 2025 | Yandex SpeechKit для RU | Лучшее качество русской речи, SSML |
| 2025 | TTS для RO и EN — открытый вопрос | Кандидат: Cartesia, пока не начато |
| 2025 | Node.js relay без хранения | Приватность, GDPR |
| 2025 | Отказ от OpenAI Realtime | $70–100/мес на пользователя, убивает юнит-экономику |
| Июнь 2026 | Live Line = full-duplex WebSocket | Режим рации неудобен для пожилых, full-duplex = естественный разговор |
| Июнь 2026 | AEC на сервере (MVP) | Быстрый старт, достаточное качество для теста |
| Июнь 2026 | Push-to-talk отклонён для Live Line | Пользователи не понимают режим рации |
