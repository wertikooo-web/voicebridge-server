## Что сделано

**Продукт:**
- Концепция полностью оформлена: ESP32-S3, push-to-talk, < 1 сек задержка
- Три формфактора определены: колонка, игрушка Lunara, сенсорный шар
- Бизнес-модель: B2C устройство + SaaS подписка + B2B лицензирование
- Бренд-голос: "Вы говорите. Они слышат. Мгновенно."

**Технические решения:**
- TTS для русского → Yandex SpeechKit (Jane / Omazh + SSML) — решено

- OpenAI Realtime — отклонён. Слишком дорого для подписочной модели (~$70-100/мес на пользователя)
- Архитектура Lunara: STT → LLM → TTS отдельными провайдерами = в 10-20 раз дешевле Realtime

## Ключевые решения (почему так)

| Решение | Причина |
|---|---|
| Yandex SpeechKit для RU | Лучшее качество, дёшево, SSML |
| Отказ от OpenAI Realtime | $70-100/мес на пользователя — убивает юнит-экономику |
| STT+TTS отдельно вместо Realtime | В 10-20 раз дешевле при том же качестве |
| Node.js relay без хранения аудио | Приватность, GDPR |
